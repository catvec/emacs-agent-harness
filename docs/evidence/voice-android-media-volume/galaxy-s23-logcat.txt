#     type:android.media.AudioTrack
#     attr:AudioAttributes: usage=USAGE_ASSISTANCE_NAVIGATION_GUIDANCE

#     session:26433 mutedState:streamVolume
#
# `USAGE_ASSISTANCE_NAVIGATION_GUIDANCE` is the usage `speechAttributes` sets,
# and `AudioAttributes.toVolumeStreamType` maps it to STREAM_MUSIC.  The
# platform's `mutedState:streamVolume` is it saying the player follows the
# stream's volume, which is the media slider and the hardware keys.

# The `C-c h` menu, level by level

Five pictures of the harness's own keys, taken from the dev instance with
`scripts/dev.sh shot` on a 140-column frame.  Each menu is the one
`C-c h`, `C-c h S`, `C-c h V`, `C-c h T` and `C-c h O` open when they
wait for a key, and the keys they show are the keys that run the
commands (`docs/design/c-c-h-menu.md`).

| Picture | What it shows |
| --- | --- |
| `c-c-h-menu-top.png` | `C-c h` alone: Sessions, Settings, Session, Views, Groups |
| `c-c-h-menu-session.png` | `C-c h S` alone: six columns in two rows, so the menu fits the frame |
| `c-c-h-menu-view.png` | `C-c h V` alone: Sessions, Views, Region |
| `c-c-h-menu-tools.png` | `C-c h T` alone: Usage, Memory, Secrets, Search |
| `c-c-h-menu-options.png` | `C-c h O` alone: Harness, Remote, Upkeep |
